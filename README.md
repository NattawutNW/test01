# QuizSuite

ระบบจัดการข้อสอบและชั้นเรียนแบบ responsive ภาษาไทย สร้างด้วย HTML, Vanilla CSS/JavaScript และ Bootstrap 5

## เริ่มใช้งาน

เปิด `index.html` ในเบราว์เซอร์สมัยใหม่เพื่อทดลองในเครื่อง หรือใช้ชุด `GoogleAppsScript/` เมื่อต้องการซิงก์ข้อมูลกับ Google

- ผู้ดูแลระบบเริ่มต้น: `admin` / `admin123`
- สมัครบัญชีผู้ใช้งานทั่วไปได้จากหน้าเข้าสู่ระบบ
- เปิด `index.html` โดยตรง: ข้อมูลเก็บใน `localStorage` ของเบราว์เซอร์เครื่องนั้น
- เปิด Web app ที่ติดตั้งจาก `GoogleAppsScript/`: ข้อมูลจะซิงก์กับชีต และโลโก้อัปโหลดไป Drive หลังจากเจ้าของ Deploy อนุญาตสิทธิ์แล้ว
- โลโก้รับไฟล์ภาพขนาดไม่เกิน 1.2 MB

## ขอบเขตการเชื่อมต่อ Google

ชุด Apps Script มีฟังก์ชันสร้างแท็บและหัวตาราง เก็บข้อมูลแยก Users, Exams, Classes, Students, Folders, Settings และ Metadata และอัปโหลดโลโก้ลงโฟลเดอร์ย่อยตามปี ดูขั้นตอนติดตั้งและข้อจำกัดด้านความปลอดภัยใน [GoogleAppsScript/README.md](GoogleAppsScript/README.md)

การซิงก์จะทำงานเมื่อเปิดแอปจาก URL ของ Apps Script เท่านั้น การเปิด `index.html` เป็นไฟล์หรือโฮสต์ static จะเก็บข้อมูลในเครื่อง การมี ID อย่างเดียวไม่อนุญาตให้ใช้ `DriveApp`; บัญชีเจ้าของ Apps Script ต้องมีสิทธิ์ในไฟล์ปลายทางและอนุญาต OAuth ก่อน

## ฟังก์ชันที่มีในรุ่นนี้

- เข้าสู่ระบบผู้ดูแลและสมัครผู้ใช้งาน
- จัดการชุดข้อสอบ โฟลเดอร์ แท็ก เฉลย และพิมพ์กระดาษคำตอบ พร้อมตัวเลือก A/ตัวเลข/อักษรไทย/กำหนดเอง และตั้งค่าหัวกระดาษกับรูปแบบจัดวาง
- จัดการชั้นเรียนและรายชื่อนักเรียน พร้อมนำเข้ารายชื่อจาก CSV และดาวน์โหลดแม่แบบ
- ดูสรุปผลสอบและสถิติเมื่อมีข้อมูลผลสอบ
- ตั้งค่าโปรไฟล์ โลโก้ ชื่อโรงเรียน และตัวเลือกการใช้งาน
- จัดการบัญชีและสิทธิ์ผู้ใช้ในหน้า Admin

การสแกนในรุ่นนี้ตรวจสอบการอนุญาตกล้องได้ แต่ยังไม่มีระบบอ่านวงกลมคำตอบ/ตรวจคะแนนจากภาพจริง โหมด static/local เหมาะสำหรับต้นแบบและใช้งานบนอุปกรณ์เดียวเท่านั้น
