# ติดตั้งการเชื่อม Google Sheets และ Google Drive

ชุดนี้ทำให้แอปที่เปิดผ่าน Google Apps Script ซิงก์ข้อมูลผู้ใช้ ข้อสอบ ชั้นเรียน นักเรียน โฟลเดอร์ การตั้งค่า ชื่อโรงเรียน และ URL โลโก้ไปยัง Google Sheets โดยสร้างแท็บและหัวตารางให้อัตโนมัติ และอัปโหลดโลโก้เข้าโฟลเดอร์ปีปัจจุบันใน Drive

## ติดตั้งครั้งแรก

1. เปิด [Google Apps Script](https://script.google.com/) ด้วยบัญชีที่มีสิทธิ์แก้ไข Google Sheet และ Google Drive ID ที่กำหนดไว้
2. สร้างโปรเจกต์ใหม่ แล้วสร้างไฟล์ให้ตรงชื่อต่อไปนี้: `Code.gs`, `Index.html`, `Styles.html`, `AppJs.html` และ `appsscript.json`
3. คัดลอกเนื้อหาจากไฟล์ชื่อเดียวกันในโฟลเดอร์นี้ไปใส่ใน Apps Script
4. บันทึก แล้วเลือก `authorizeQuizSuiteResources` จากเมนูฟังก์ชันและกด Run หนึ่งครั้งเพื่ออนุญาตสิทธิ์ Sheets และ Drive
5. เลือก Deploy → New deployment → Web app
6. ตั้ง Execute as เป็นบัญชีเจ้าของไฟล์ และจำกัด Who has access เป็นบัญชี/โดเมน Google ของโรงเรียนเท่านั้น ห้ามเผยแพร่เป็น Anyone เพราะฟังก์ชันซิงก์เป็น endpoint ที่เรียกจากหน้าเว็บได้
7. เปิด URL ของ Web app ที่ deploy แล้ว ข้อมูลชุดแรกจะถูกสร้างในชีตอัตโนมัติ การแก้ไขในแอปจะซิงก์หลังจากหยุดแก้ไขประมาณ 0.7 วินาที
